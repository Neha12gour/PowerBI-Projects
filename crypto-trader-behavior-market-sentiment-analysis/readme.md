# Crypto Trader Behavior Analysis by Market Sentiment

## 📌 Project Overview
This project analyzes the relationship between **market sentiment (Fear & Greed Index)** and 
**crypto trader performance** using historical trading data from **Hyperliquid**.

The objective is to uncover how different sentiment regimes influence:
- Trading activity
- Profitability
- Win rates
- Risk-adjusted performance
- Trade sizing behavior

The analysis is presented through an **interactive Power BI dashboard** supported by a 
detailed analytical report.

---

## 🔍 Key Insights

### 📉 Fear Regime
- Highest trading activity
- Largest average trade size
- Highest net profitability
- Indicates panic-driven mispricing opportunities

### 📈 Extreme Greed
- Highest win rate (~46%)
- Lower trade volume
- Momentum-driven market conditions

### ⚖ Neutral Market
- Weakest performance
- Lower risk-adjusted returns
- Reduced trading edge

### 🧠 Strategic Insight
High win rate alone does not guarantee profitability.  
**Trade volume, sizing, and sentiment context** play a crucial role in long-term performance.
